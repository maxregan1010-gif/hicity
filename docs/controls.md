# راهنمای کنترل — شهر طوفان

## 🖥 کامپیوتر — پیاده

| کلید | عملکرد |
| --- | --- |
| W / A / S / D | حرکت به جلو / چپ / عقب / راست (نسبت به دوربین) |
| Shift | دویدن (استقامت مصرف می‌کند؛ با تمام شدن آرام راه می‌روید) |
| Space | پرش |
| E | تعامل — صحبت با NPC، ورود به فروشگاه، تخت، کمد لباس، گاوصندوق، پمپ بنزین، تعمیرگاه، بانک، دفتر استخدام، مکان مخفی، شروع مسابقه |
| F | ورود/خروج از نزدیک‌ترین خودرو |
| X | جابه‌جایی سلاح (مشت → چوب بیسبال → کلت) |
| R | ضربه/شلیک (نگه دارید برای شلیک پیوسته) |
| C | تغییر فاصله دوربین (نزدیک/متوسط/دور) |
| ماوس (نگه‌داشتن و کشیدن) | چرخش دوربین |
| اسکرول | زوم دوربین |
| I | پروفایل شخصیت (پول، شغل، لباس، سابقه) |
| P | تلفن همراه (نقشه، گاراژ، بانک، درخواست خودرو، ذخیره…) |
| M | نقشه بزرگ شهر |
| Tab / Esc | منوی توقف |

## 🚗 کامپیوتر — خودرو / موتور / قایق

| کلید | عملکرد |
| --- | --- |
| W / S | گاز / ترمز و دنده عقب |
| A / D | فرمان |
| Space | ترمز دستی (سوختن لاستیک + صدا) |
| H | بوق (نگه دارید) |
| C | نمای بیرونی → کاپوت → داخل کابین |
| F | پیاده شدن |
| L | چراغ‌های جلو/عقب |
| Shift | (فقط هواپیما) گاز موتور |

| کلید | عملکرد |

| Shift | بالا رفتن (کلکتیو) |
| Space | پایین آمدن |
| W / S | حرکت جلو / عقب |
| A / D | چرخش (یو) |

## ✈️ هواپیما

| کلید | عملکرد |
| --- | --- |
| Shift | گاز موتور (تا ۱۵m/h سرعت برای برخاستن) |
| W / S | دماغه پایین (شیرجه) / دماغه بالا (اوج گرفتن) |
| A / D | چرخش — روی باند هم کار می‌کند |

## 🗺 نقشه و GPS

- **M**: نقشه بزرگ — با کلیک روی هر نقطه، مقصد GPS تعیین می‌شود و مسیر روی نقشه کوچک هم می‌آید.
- آیکون‌ها: 🏠 خانه، 🚓 پلیس، 🏦 بانک، 🏥 بیمارستان، ⛓️ زندان، 🚗 نمایشگاه‌ها، 🛒 فروشگاه‌ها، ⛽ پمپ بنزین، 🔧 تعمیرگاه، 🧰 دفاتر استخدام، 🏁 مسابقه، 💎 مکان مخفی.
- نزدیک شدن به مقصد روی نقشه کوچک → پیام «به مقصد رسیدید».

## 📱 موبایل

| کنترل | عملکرد |
| --- | --- |
| جوی‌استیک پایین چپ | حرکت هشت‌جهته (پیاده) — در رانندگی: فرمان + گاز/ترمز |
| کشیدن انگشت در نیمه راست | چرخش دوربین (بدون تداخل با جوی‌استیک) |
| 🏃 دویدن | نگه دارید |
| ⤒ پرش | ضربه |
| 💬 تعامل | ضربه (مثل E) |
| 🚪 خودرو | سوار/پیاده شدن |
| ✊ سلاح | جابه‌جایی سلاح |
| 💥 حمله | نگه دارید (حمله/شلیک) |
| ⛽ گاز / 🛑 ترمز / ◀ ▶ فرمان | چیدمان دکمه‌ای رانندگی (قابل انتخاب در تنظیمات) |
| ▲▼ / ⬆⬇ | بالا/پایین و جلو/عقب برای هلیکوپتر و هواپیما |
| 📢 بوق، 📷 دوربین، 🚪 خروج | حین رانندگی |
| 📱 تلفن، 🗺️ نقشه، ⚙️ منو | بالای صفحه |
| Multi-Touch | حرکت + دوربین + دکمه‌ها هم‌زمان کار می‌کنند |

### تنظیمات کنترل موبایل (⚙️ منو → تنظیمات → موبایل)
- حساسیت دوربین لمسی، اندازه جوی‌استیک، اندازه دکمه‌ها، شفافیت کنترل‌ها
- انتخاب چیدمان رانندگی: «جوی‌استیک» یا «دکمه‌های فرمان»
- **حالت ویرایش چیدمان**: روشن کنید و دکمه‌ها را با انگشت جابه‌جا کنید؛ با خاموش کردن، ذخیره می‌شود.
- بازنشانی چیدمان به حالت پیش‌فرض

| آنالوگ راست | دوربین |

| Start / Back | منو / نقشه |
