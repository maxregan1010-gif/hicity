# معماری سیستم‌ها — شهر طوفان

## نمای کلی

بازی از **۳۰ ماژول JavaScript** مستقل تشکیل شده که همه از طریق فضای نام سراسری `TC` با هم ارتباط دارند (بدون ES Modules تا `file://` هم کار کند). حلقه اصلی در `main.js` است و هر فریم همه سیستم‌ها را به ترتیب به‌روز می‌کند.

```
main.js (بوت + حلقه + ورودی کیبورد)
 ├─ core.js        فضای نام TC، پیکربندی، PRNG قطعی، باس رویداد، تنظیمات، Virtual Input
 ├─ engine.js      Babylon.js: صحنه، نور خورشید، سایه، پس‌پردازش، کیفیت، FPS cap
 ├─ world.js       تکسچرهای رویه‌ای (canvas)، جاده‌ها، ساختمان‌ها، POI ها، طبیعت، دریا، آسمان
 ├─ worldProps.js  درخت/چراغ/نیمکت/تابلو با Thin Instance، چراغ راهنمایی چرخه‌ای
 ├─ navigation.js  گراف جاده (تقاطع‌ها + حلقوی + فرودگاه/بندر/روستا)، A*، مسیر با آفست لِین
 ├─ physics.js     Spatial-hash AABB، resolveCircle، sweep، دید AI، ارتفاع زمین، آب/ساحل
 ├─ daynight.js    زمان بازی، خورشید/ماه/آسمان، چراغ‌های شب، پنجره‌های روشن
 ├─ weather.js     آفتابی/ابری/بارانی/مه/طوفان، ذرات باران، رعد، آسفالت خیس
 ├─ audio.js       WebAudio رویه‌ای: موتور/ترمز/بوق/آژیر/باران/پرنده/موسیقی مولد + پن سه‌بعدی
 ├─ player.js      ریک بدن، انیمیشن رویه‌ای (قدم/دویدن/پرش/شنا/نشستن)، لباس روی مدل، سلامت/استقامت، تعامل، شلیک
 ├─ camera.js      دوربین سوم‌شخص با برخورد، دوربین خودرو (۳ حالت)، لرزش
 ├─ vehicles.js    ۲۲ وسیله با تعریف مشخصات، ساخت مش، فیزیک آرکید، آسیب/دود، سوخت، چراغ، در، گاراژ
 ├─ npc.js         استخر عابرها (اسپاون/حذف بر اساس فاصله)، قدم زدن پیاده‌رو، فرار، مکالمه، ترافیک با AI
 ├─ police.js      ۶ سطح تعقیب، واحدهای پیاده/خودرو، دید و جست‌وجو، موانع، دستگیری → زندان
 ├─ prison.js      محوطه + سلول‌ها + غذاخوری + دفتر + اتاق ملاقات، نگهبان/زندانی AI، شمارش محکومیت
 ├─ economy.js     پول نقد/بانک، تراکنش‌ها، واریز/برداشت/انتقال، حقوق پایان روز
 ├─ jobs.js        ۱۲ شغل، فرآیند استخدام، حضور، غیبت (۲ روز = اخراج)، استعفا، حقوق
 ├─ jobMissions.js شیفت کاری + ژنراتور مأموریت برای هر شغل (تاکسی/پیک/پلیس/بانک/کامیون/…)
 ├─ missions.js    داستان ۸ فصل + کات‌سین سینمایی + انتخاب پایان + مسابقه + مکان مخفی
 ├─ housing.js     داخل خانه، تخت/کمد/گاوصندوق/گاراژ، خواب (پیشروی روز)، ارتقای مسکن
 ├─ shops.js       فروشگاه‌ها (غذا/لباس/تجهیزات/اسلحه)، بانک، بیمارستان، تعمیرگاه، پمپ بنزین، هتل
 ├─ dealerships.js ۶ نمایشگاه، پیش‌نمای چرخشی، خرید نقد/بانکی، فروش با استهلاک
 ├─ map.js         رندر پایه شهر به canvas، نقشه کوچک چرخشی، نقشه بزرگ با زوم/مقصد/GPS
 ├─ hud.js         پول/سلامت/مأموریت/شغل/خودرو/تعقیب/اعلان/ساعت/منطقه/GPS
 ├─ ui.js          منوها، تلفن، تنظیمات کامل + تغییر کلید، کمد، گاراژ، دیالوگ، تأیید
 ├─ save.js        IndexedDB چنداسلته + ذخیره خودکار
 ├─ mobileControls.js جوی‌استیک، دوربین لمسی، دکمه‌های متناسب، ویرایش چیدمان، Multi-Touch
 └─ gamepad.js     Gamepad API + لرزش
```

## اتصال‌های کلیدی (همه واقعی و زنده)

- **خرید خودرو** → کم شدن پول (`economy.spend`) → ثبت در گاراژ (`vehicles.playerGarage`) → تحویل در خانه/تلفن با هزینه پیک.
- **مأموریت شغلی** → مارکر روی نقشه کوچک و بزرگ → پاداش واقعی به اقتصاد → پیشرفت در پنل HUD.
- **جرم** → `police.reportCrime` → سطح تعقیب → اسپاون پلیس → دستگیری → جریمه (کم شدن پول) + انتقال به زندان با زمان متناسب → آزادی.
- **غیبت شغلی** → پایان روز → ۲ روز متوالی → اخراج خودکار + ثبت در سابقه.
- **تغییر لباس** → `inventory.equip` → اعمال رنگ/مدل روی مش شخصیت همان لحظه.
- **HUD** → همه مقادیر مستقیماً از `TC.Economy / TC.Player / TC.Police / TC.JobMissions` خوانده می‌شوند.
- **ذخیره** → `Save.collect()` همه سیستم‌ها را serialize می‌کند؛ بارگذاری همه را بازمی‌گرداند.
- **کنترل موبایل** → `TC.Virtual` (همان لایه‌ای که کیبورد و گیم‌پد می‌نویسند).

## بهینه‌سازی

- **Merge** ساختمان‌ها بر اساس متریال (کل شهر ~۱۵ mesh استاتیک بزرگ)
- **Thin Instance** برای درخت‌ها، چراغ‌ها، مبلمان شهری (هزاران نمونه با چند draw call)
- **استخر NPC/ترافیک**: تعداد بر اساس کیفیت (۸ تا ۳۰ عابر، ۸ تا ۲۶ خودرو)، اسپاون/حذف با فاصله
- **حذف جاده‌های دور با مه** + fog distance بر اساس کیفیت
- **سایه دنبال‌کننده بازیکن** با frustum کوچک (۱۳۰ متر)
- **hardware scaling** برای موبایل (کیفیت کم = رندر با رزولوشن پایین‌تر)
- **FPS cap** و **کاهش کیفیت خودکار** در افت فریم
- **صدا رویه‌ای** (بدون فایل) و پن/گین دستی برای کاهش هزینه

## چرخه شبانه‌روز

یک روز کامل = ۲۴ دقیقه واقعی. ساعت بازی در `TC.G.time` (ثانیه). پایان روز → رویداد `day:end` (حقوق، غیبت) → `day:new` (روز جدید، روز هفته فارسی).

## داده‌های قطعی شهر

تولید شهر با `M.resetSeed(1337)` انجام می‌شود؛ پس هر بار اجرا **دقیقاً همان شهر** ساخته می‌شود (نقشه، POI ها و مکان‌های مخفی ثابت می‌مانند و با ذخیره هماهنگ‌اند).
