# شهر طوفان — Toofan City ⚡

یک بازی جهان‌باز سه‌بعدی فارسی با الهام از GTA V و GTA San Andreas — ساخته‌شده با **HTML5 + Babylon.js (WebGL2)**.

شخصیت اصلی **آرش راد** است؛ تازه‌واردی که با یک چمدان به شهر طوفان می‌آید و در ۸ فصل داستانی «طوفان می‌آید» سرنوشت شهر را تغییر می‌دهد.

---

## ✨ امکانات

- **شهر وسیع چندمنطقه‌ای**: مرکز طوفان (آسمان‌خراش‌ها)، خیابان تجاری پارس، شهرک آفتاب، کوی زیتون، ویلای شاه‌نشین، منطقه صنعتی، بندر شرقی، فرودگاه بین‌المللی آرش، پارک بهاران، ساحل مرجان، جنگل سبزان، کوه‌های پارسه و بزرگراه حلقوی
- **۲۲ وسیله نقلیه**: خودرو اقتصادی/اسپرت/لوکس/کلاسیک، تاکسی، وانت، شاسی‌بلند، کامیون، اتوبوس، موتورسیکلت، دوچرخه، قایق، یخت، دو هواپیما و هلیکوپتر — با فیزیک مستقل، سوخت، آسیب، تعمیرگاه و پمپ بنزین
- **پلیس با ۶ سطح تعقیب**: گزارش جرم، تعقیب پیاده و خودرویی، موانع جاده‌ای، جست‌وجوی منطقه‌ای، کاهش سطح تعقیب، دستگیری و جریمه
- **زندان قابل ورود**: سلول‌ها، راهرو، غذاخوری، حیاط، دفتر مدیریت، نگهبان‌ها و زندانی‌ها با AI، محکومیت متناسب با جرائم
- **۱۲ شغل واقعی** با دفتر استخدام، هزینه استخدام، حقوق روزانه، شیفت کاری، مأموریت اختصاصی هر شغل، غیبت و اخراج خودکار بعد از ۲ روز
- **اقتصاد یکپارچه**: پول نقد + حساب بانکی، واریز/برداشت/انتقال، تاریخچه تراکنش، خرید/فروش خودرو با قیمت‌گذاری بر اساس سلامت و کارکرد
- **۶ نمایشگاه خودرو** با بازدید سه‌بعدی چرخشی، مشخصات کامل (سرعت/شتاب/هندلینگ/ظرفیت/سوخت) و گاراژ شخصی
- **خانه شخصی** با اتاق خواب، پذیرایی، آشپزخانه، حمام، کمد لباس واقعی (تغییر روی مدل)، پارکینگ، خوابیدن و ذخیره
- **داستان ۸ فصلی** با کات‌سین سینمایی، زیرنویس، انتخاب بازیکن و دو پایان‌بندی متفاوت
- **چرخه شبانه‌روز و آب‌وهوا**: طلوع/غروب، چراغ‌های خیابان و پنجره‌های شب، باران با آسفالت خیس، رعد و برق، مه
- **نقشه کوچک چرخشی + نقشه بزرگ** با آیکون همه مکان‌ها، تعیین مقصد و مسیر GPS
- **کنترل کامل موبایل**: جوی‌استیک مجازی هشت‌جهته، دوربین لمسی، Multi-Touch واقعی، دکمه‌های متناسب پیاده/رانندگی/هوایی، جابه‌جایی دکمه‌ها با کشیدن، تنظیم اندازه/حساسیت/شفافیت، Safe Area، قفل افقی
- **پشتیبانی دسته بازی** (بلوتوث روی موبایل و USB روی PC)
- **ذخیره ۳ اسلته + خودکار** با IndexedDB — ادامه بازی از همان نقطه
- **صدای رویه‌ای WebAudio**: موتور، ترمز، بوق، آژیر، باران، رعد، پرنده، محیط شهر، موسیقی مولد — بدون هیچ فایل صوتی خارجی

## 🖥 اجرا روی کامپیوتر

### روش ۱ (پیشنهادی): RUN.bat
1. پوشه بازی را باز کنید و روی **RUN.bat** دوبار کلیک کنید.
2. بازی در مرورگر پیش‌فرض روی `http://localhost:8422` باز می‌شود.
3. اگر Python یا Node.js روی سیستم نباشد، فایل `index.html` مستقیماً باز می‌شود (در اکثر مرورگرها کار می‌کند، چون بازی بدون ماژول ES نوشته شده).

### روش ۲: باز کردن مستقیم
`index.html` را در Chrome/Edge/Firefox باز کنید.

### روش ۳: سرور دستی
```bash
cd ToofanCity
python -m http.server 8422
# سپس: http://localhost:8422
```

**نیاز سیستم**: مرورگر با WebGL2 (Chrome/Edge/Firefox/Safari جدید)، ۴GB رم. برای کیفیت بالا کارت گرافیک متوسط کافی است.

## 📱 اجرا روی موبایل (Android / iOS)

1. پوشه بازی را به گوشی منتقل کنید (کابل، تلگرام/ذخیره‌سازی ابری یا میزبانی).
2. **ساده‌ترین راه**: پوشه را روی یک میزبان استاتیک رایگان بگذارید (GitHub Pages، Netlify Drop، Vercel) و آدرس را در مرورگر گوشی باز کنید.
3. **بدون اینترنت**: در اندروید با اپ «Simple HTTP Server» یا Termux (`python -m http.server 8422`) پوشه را میزبانی کنید و در Chrome گوشی `http://localhost:8422` را باز کنید.
4. در iOS، فایل‌ها را با اپ‌هایی مثل «Koder» یا «Documents» به‌صورت محلی باز کنید.
5. گوشی را **افقی** بگیرید — بازی برای حالت افقی بهینه شده است.

> نکته: بعضی مرورگرهای موبایل فایل‌های JS را از `file://` کامل باز نمی‌کنند؛ در این حالت حتماً از میزبانی محلی (راهکار ۳) استفاده کنید.

## 🗂 ساختار پروژه

```
Game/
  index.html          نقطه ورود
  RUN.bat             اجرای محلی (Windows)
  css/                استایل‌ها (base, hud, menus, mobile)
  js/                 ۳۰ ماژول بازی (core, engine, world, player, vehicles, police, prison, jobs, ...)
  assets/js/babylon.js  موتور Babylon.js (محلی، بدون اینترنت)
  assets/fonts/       فونت وزیرمتن (محلی)
  docs/               راهنمای کنترل و معماری سیستم‌ها
```

## ⚙️ تنظیمات پیشنهادی

- موبایل ضعیف: کیفیت «کم» + محدودیت ۳۰FPS (تنظیمات → گرافیک)
- موبایل متوسط/تبلت: «متوسط» یا «زیاد»
- کامپیوتر: «زیاد» یا «فوق‌العاده»
- «کاهش خودکار کیفیت» روشن بماند تا بازی همیشه روان بماند.
